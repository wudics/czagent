> 项目：czagent 桌面智能体
> 本文档：开发总览与进度跟踪（living document，随迭代持续更新）

## 1. 项目一句话

一款跨平台（Windows / macOS / Linux）桌面智能体：自研 agent loop + 多平台大模型接入（DeepSeek / SiliconFlow / Agnes / 任意 OpenAI 兼容）+ 工具链 + 多会话并发 + 长上下文压缩，支持「自主决策」与「脚本编排」两种执行模式。

## 7. 全局开发约定

- **包管理**：pnpm（全局安装，直接 `pnpm <cmd>` 执行）；`pnpm install` / `pnpm --filter <pkg> <script>`。
- **国内源**：npm 走 npmmirror、electron 走 npmmirror 镜像、pip 走清华源（见 packaging.md §3）。
- **提交规范**：`feat / fix / refactor / docs / chore / test / perf` + 简述。
- **代码规范**：TypeScript strict；禁止提交密钥；core 不依赖 Electron/UI。
- **每轮验收**：本轮结束必须 `pnpm dev` / `pnpm dev:ui` 可运行，用户上手体验后再进入下一轮。
