## 遇到的问题与解决

| 问题 | 解决 |
|---|---|
| pnpm 未安装，corepack 无管理员权限 | `npm install -g pnpm`（全局前缀为用户目录，无需提权） |
| pnpm 11 默认忽略依赖 build 脚本 → electron 二进制未下载 | `pnpm-workspace.yaml` 配置 `onlyBuiltDependencies: [electron, esbuild, ...]`；electron 安装脚本手动以 `ELECTRON_MIRROR` 重跑成功 |
| pnpm 11 不再读取 `package.json` 的 `pnpm` 字段 | 迁移到 `pnpm-workspace.yaml` |
| core typecheck 缺 `@types/node` | core devDependencies 补充 |
| desktop `@shared` 别名 TS 不识别 | tsconfig `paths` 映射 |
| `window.czagent` 全局类型不生效 | preload `index.d.ts` 与 `index.ts` 同名被 TS 忽略，改为独立 `src/renderer/src/env.d.ts` |
| `@vitejs/plugin-react@6` 要求 vite ^8，与 electron-vite 5（vite 7）冲突 | 降到 `@vitejs/plugin-react@^5` |
| `electron-builder --dir` 卡在 winCodeSign 下载（无镜像 env） | 显式 `ELECTRON_BUILDER_BINARIES_MIRROR` + `ELECTRON_MIRROR` 环境变量后通过 |
