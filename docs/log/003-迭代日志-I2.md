## 遇到的问题与解决

| 问题 | 解决 |
|---|---|
| settings store 内部 `persist` 未在接口声明 | 接口补 `persist(next)`（内部用，类型安全） |
| localStorage 在 Node 测试环境不存在 | settingsStorage 用 `typeof localStorage !== 'undefined'` 守卫，回退内存缓存 |
| 删除当前绑定模型后绑定悬空 | `ensureBindingModelId` 自动回退到该能力首个启用模型 |
