## 遇到的问题与解决

| 问题 | 解决 |
|---|---|
| core `Storage` 用 `import type` 导入却运行时 `new` → ReferenceError | 改为值导入 |
| 助手消息只 `finalizeMessage`（UPDATE）未 `insertMessage` → 分页只返回 user 消息 | 流式开始前先 insert（空 parts），delta 时 `updateMessageParts` 增量持久化 |
| 测试在流未结束时 closeDb → “database connection is not open” | 测试等待 `message.complete` 后再关库 |
| Windows 临时目录 afterAll 删除 EPERM | try/catch + 先删 WAL/db 文件再删目录 |
| `ChatMessage` 缺 `cost` 字段 | provider.ts 补 `cost?: number` |
| SessionManager 缺 `onEvent`（契约要求） | 内部 listener 集合 + 构造注入 opts.emit 作为初始订阅 |
| electron-vite 外部化：better-sqlite3 非 desktop deps 不会被 externalize | desktop deps 补 better-sqlite3/drizzle-orm |
| pnpm 11 `allowBuilds` 占位导致 better-sqlite3 构建脚本未执行 | 显式 `allowBuilds: { better-sqlite3: true }`（实际为 N-API 预编译，无需编译） |
| mockProvider.updateSettings 用纯合并未落盘 | 补 `saveSettings(next)` |
