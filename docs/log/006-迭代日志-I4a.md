## 目标

真实 agent 从"单轮对话"升级为"自主多轮调用工具"：能读文件 / 搜代码 / 抓网页；越界或敏感操作走权限系统（弹窗询问）。

## 完成项

- [x] **协议引擎 tool_calls 流式**（`core/src/llm/client.ts`）：按 index 累积 `tool_calls`（id/name 首帧、arguments 分片、`finish_reason='tool_calls'` JSON 解析）；`LLMEvent` 扩展 `tool-call-start/delta/tool-call`；`LLMChatMessage` 支持 `toolCalls`/`toolCallId`（请求体回填 assistant.tool_calls + role:tool）
- [x] **工具系统**（`core/src/tools/`）：`ToolDef/ToolContext` + `ToolRegistry`（register/resolve/toOpenAI）+ 4 个只读工具：
  - `read`（offset/limit、2MB 上限、行头信息）
  - `grep`（递归 + 正则/字面回退 + include glob + 结果上限）
  - `glob`（fast-glob）
  - `webfetch`（fetch → HTML→文本截断）
- [x] **权限系统**（`core/src/permission/`）：agent.allow/deny/ask 优先 → settings 默认规则 → 工具默认 map；`pathInside`（Windows 大小写不敏感）+ `extractTargetPath` 供弹窗展示
- [x] **多轮 agent loop**（`session-manager.ts` `runLoop`）：`agent.steps`（默认 16）上限；每轮注入 tools（JSON Schema）；流式 → 若 tool_calls → 逐个权限判定（allow/deny/ask→`permission.request` 事件→用户决定）→ 执行 → tool-call/tool-result part 落库并事件推送 → 下一轮回填（assistant.tool_calls + role:tool）；无调用才收尾
- [x] **SessionManager**：`resolvePermission` 真实实现（pendingAsks 映射 + abort→deny）；`storage.upsertMessage`（错误路径未 insert 也能落库）；cwd 默认 `os.homedir()`
- [x] **渲染层**：新建会话 cwd 默认留空（提示默认用户主目录）；权限弹窗/工具卡片复用 I1 组件、事件链复用 I3a
- [x] **依赖**：`fast-glob`

## 遇到的问题与解决

| 问题 | 解决 |
|---|---|
| 错误路径（无模型/无 key）消息未 insert，`finalizeMessage`（UPDATE）落 0 行 | storage 新增 `upsertMessage`（`INSERT ... ON CONFLICT DO UPDATE`） |
| `resolveForTool` 参数类型草稿污染 | 重写为接收 `AgentDef \| undefined` |
| read 测试行数断言（尾换行 → 4 段） | 修正测试为 `共 4 行` |
| 工具结果序列化 | `toolResultContent`（string 原样 / 对象 JSON / error 前缀）供 role:tool 回填 |
