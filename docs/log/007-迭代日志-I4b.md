## 目标

接入 bash 工具（node-pty），agent 能执行终端命令；危险命令需确认、同工具同参重复调用触发询问；命令超时兜底。

## 完成项

- [x] **依赖**：`@lydell/node-pty@1.2.0-beta.15`（core deps + desktop deps，electron-vite 外部化；desktop optionalDependencies 含 6 个平台 prebuilt：win32-x64/arm64、darwin-x64/arm64、linux-x64/arm64）
- [x] **bash 工具**（`core/src/tools/bash.ts`）：
  - 平台适配：win32→`powershell.exe -NoProfile -NonInteractive -Command`；Linux/mac→`bash -c`
  - 以会话 cwd 运行（pty spawn cwd）
  - 命令超时 60s（`setBashTimeoutMs` 可测注入）→ 抛「命令执行超时」
  - 用户停止（abort）→ pty.kill 中断
  - 输出上限 30k + **ANSI 转义剥离**（颜色/光标/标题）
  - 返回 `exitCode: X\n\n<输出>`
- [x] **命令安全分类**（`permission/index.ts` `classifyBashCommand`）：危险/破坏性命令（`rm -rf /`、`del /f /s`、`format`、`shutdown`、`mkfs`、`dd`、fork bomb、`curl|sh`、`iwr|iex` 等）→ ask；其余放行（shell 以会话 cwd 运行，天然在 cwd 内）
- [x] **resolveForTool bash 特判**：安全命令直接放行；危险命令走正常权限判定（默认 ask）
- [x] **doom-loop**：同工具同参连续 3 次 → `requestPermission` 询问（read 等 allow 工具也会触发），允许则重置计数
- [x] **注册表**：`createDefaultRegistry` 含 bash；renderer TOOL_IDS 已含 bash

## 遇到的问题与解决

| 问题 | 解决 |
|---|---|
| 超时需测注入，`export let` 在 ESM 下导入方只读 | 改为 `setBashTimeoutMs()` setter + 模块内 `let` |
| 超时后 mock pty kill 不触发 onExit → promise 永不释放 | 超时处理器显式 `resolveExit?.(0)` 兜底 |
| mock 对象需满足 IPty 类型 | mockImplementation 返回 `as never` |
| pty 输出含 ANSI 转义 | `stripAnsi` 剥离后再返回 |

## 说明

- **非持久 shell**：本迭代为「一次命令一个 pty 子进程」；交互式命令（需要持续输入）暂不支持，后续可升级为每会话持久 shell 会话。
- cwd 边界靠「shell 以会话 cwd 启动 + 危险命令分类」实现；更细的路径级白/黑名单留 P3 高级权限。
