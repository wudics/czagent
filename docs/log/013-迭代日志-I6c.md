## 完成项

### 1. 多会话并发（决策 21）
- [x] 信号量 + 队列：`sendMessage` 时活跃 runLoop ≥ `general.maxConcurrency` → 状态 `queued`（DB+事件）入队；`startLoop` finally 释放槽位 → `pumpQueue` 按序补位（并行占满）
- [x] 防重入：同会话 running/queued 再发 → 抛错（渲染层 catch 提示，不中断输入）
- [x] `stopSession`：排队中 → 出队回 idle（不占槽位）；运行中 → abort（原逻辑）；`deleteSession` → 出队丢弃

### 2. 权限询问内联化（并发前置修复 + plan-exit 交互载体）
- [x] `chat store` 全局单例 `pendingPermission` → **`permissions store` 按会话列表**（`pending: {sessionId, request}[]`），resolve 按 id 移除——修复多会话并发下弹窗互相覆盖、请求永挂的问题
- [x] 全局 `PermissionDialog` 删除 → **`ChatArea` 内嵌 `PermissionCard`**（每会话各自渲染，互不覆盖）：工具名/参数/允许·总是允许·拒绝
- [x] `main.tsx` 挂载 permissions store 事件订阅；`Sidebar` 会话行显示"待确认"标记（amber）

### 3. plan 模式（决策 18：用户切换 + agent 自主进出）
- [x] 新工具 `plan`（提交计划文本）/ `plan-exit`（工具内部 `ctx.ask` 用户确认 → `ctx.setAgent('build')`；拒绝返回提示继续规划）
- [x] `ToolContext` 增 `tempDir`、`setAgent`（SessionManager 注入）；`registry.resolve([])` 排除内部工具 `plan/plan-exit`（仅 plan agent 显式持有）
- [x] runLoop **agent 每轮按会话 agentId 重新解析** → plan-exit 切换后当前 loop 立即生效
- [x] plan agent 默认定义清理（tools 去掉不存在的 websearch/todowrite，改为 plan/plan-exit）+ 提示词引导
- [x] `ConfigStore.read` 迁移：默认权限规则只追加缺失项；builtin plan agent 合并补齐 plan/plan-exit
- [x] UI：NewSessionDialog 加 Agent 下拉；**会话头部 `SessionHeader`**（标题+排队徽标+Agent 下拉，运行/排队禁用，唯一切换入口）；RightPanel 保持只读展示

### 4. 标题自动生成（方案 C，用户定制）
- [x] 配置 `general.titleAutoRounds`（默认 **1**，0=关闭；GeneralTab 数字输入+提示）；历史会话迁移默认视为 user（绝不覆盖）
- [x] sessions 表迁移：`title_source TEXT DEFAULT 'user'`（`openDb` 按 PRAGMA 补列）；`SessionMeta.titleSource?`
- [x] 行为：runLoop 完成后，真实用户消息数 ≤ rounds 且 `title_source === 'auto'` 且有实际文本 → 会话模型单次调用生成 ≤20 字标题（内部路径保持 auto）；UI 改标题（patchSession）→ 锁定为 user
- [x] rowToSession 映射 titleSource（初版遗漏导致标题不生成，测试暴露后修复）

## 实施中发现并修复的问题
- **plan-exit 双重询问**：规则层 ask + 工具内部 ctx.ask 会连续弹两次确认 → 规则层放行（plan-exit: allow），确认只保留工具内部一次
- **标题不生成**：rowToSession 未映射 title_source → getSession.titleSource undefined → maybeAutoTitle 早退
- **chat store 事件过滤**：权限事件原本被按会话过滤丢弃 → permissions store 全局订阅（不按会话过滤）
