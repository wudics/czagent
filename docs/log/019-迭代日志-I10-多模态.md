## 目标

把能力绑定（embedding/rerank/image-generation/video-generation/tts/asr）变成 6 个可调用工具：执行时按绑定取模型与 provider，调 SiliconFlow / Agnes 端点。

## 完成项

### 1. 六个工具（`core/src/tools/multimodal.ts`）
- [x] **embed**：`{text|texts}` → `/v1/embeddings` → 向量 JSON
- [x] **rerank**：`{query, documents, topN?}` → `/v1/rerank` → 相关性排序
- [x] **image-generate**：`{prompt, size?, ratio?, image?[], model?}` → `/v1/images/generations`
  - **双 provider 路由**：模型名 `agnes-*` → Agnes 格式（size 档位 1K–4K + ratio、`return_base64`/`extra_body.response_format`——顶层 response_format 是官方文档明令禁止的坑）；其它 → SiliconFlow 格式（`image_size` 精确尺寸）
  - 图生图/多图合成：`image` 参数支持 **URL 或本地文件路径**（本地 → base64 Data URI）
  - 生成结果 → base64 dataUrl → **image part 直接显示在消息流** + 文件落盘 + file chip；Agnes 请求超时放宽 360s（官方建议）
- [x] **video-generate**：`{prompt, seconds?, aspectRatio?, mode?, firstFrame?, lastFrame?, images?, audios?, model?}`
  - Agnes：`POST /v1/videos` 创建 → `GET {base}/agnesapi?video_id=…&model_name=…` **轮询（2s 间隔，超时 20 分钟，signal 可中断）**；size 固定 720P；keyframe/reference 模式参数完整暴露（媒体**仅公开 URL**——本地文件不受支持，文档约束）
  - SiliconFlow：`/v1/video/submit` → `/v1/video/status` 轮询
  - 视频 URL → 下载落盘 mp4 → file chip
- [x] **tts**：`{text, voice?}` → `/v1/audio/speech` → mp3 落盘 + file chip
- [x] **asr**：`{file}`（本地音频）→ multipart `/v1/audio/transcriptions` → 转写文本

### 2. 富输出基建（`core/src/tools/rich-output.ts`）
- [x] `richOutput()/isRichToolOutput()`：工具可返回 `{text, images?, files?}`——SessionManager 识别后把 images/files 追加为**独立 image/file part**（消息流直接呈现），tool-result 只保留文本给模型
- [x] 接入三处：runLoop 工具执行、runScriptTool（脚本）、runSubAgent（取 text）

### 3. 接入
- [x] registry 注册 6 工具（build 全量）；默认权限全部 allow（迁移自动补齐）；`ctx.tools` 脚本自动可用

## 真机反馈修复（TTS Invalid voice / 视频卡执行中）

- [x] **TTS 20047 Invalid voice**：`voice` 是必填参数（格式 `<model>:<音色>`）——未传时默认 **`<绑定模型>:alex`**；简写（不含 `:`）自动补模型前缀；完整格式/`speech:` 自定义 URI 原样透传。工具描述列出 8 个系统预置音色（alex/benjamin/charles/david/anna/bella/claire/diana）并提示 MOSS-TTSD 使用 `[S1]/[S2]` 对话脚本格式
- [x] **视频"一直执行中"**（SF 已计费完成但工具不结束）：官方状态值是 **`'Succeed'`**（非 Succeeded），此前比较 `succeeded` 永不匹配 → 改为 `['succeed','succeeded','completed']` 大小写不敏感匹配
- [x] **Agnes 完成结果提取**：视频地址在 **`metadata.url`**（此前取 `video_url/url` 取不到）；轮询响应含**真实 `progress` 0–100** → reportProgress 直接显示真实百分比
- [x] 进度上报接入富输出路径：video 轮询每轮上报状态/真实百分比/已等待时间；image 生成期间 2s 间隔计时上报（图片为单次同步请求，API 无进度接口，只能计时）
- 测试：SF `'Succeed'` 匹配、Agnes `metadata.url` 提取 + 真实百分比上报、tts 默认 voice/简写补前缀/完整透传

## 真机反馈修复 第二批（视频卡"创建中"根因 + 移除 model 覆盖参数）

- **只读诊断真机会话**（"CS1.6五杀集锦生成受阻"）：失败链 = ① Agnes mode 文档过时（已修）→ ② 模型自行试出 `ti2vid` 后撞 429 免费限流 → ③ **agent 幻觉传入 `model:"agnes"`（无效 id）**，litellm 对未知模型挂起
- [x] **移除全部 8 个多模态工具的 `model` 覆盖参数**：模型一律来自能力绑定（设置 → 模型 换绑），agent 传入的 model 字段被忽略——根治幻觉乱填；绑定即模型，换绑走设置
- [x] **Agnes 视频按模型代际路由**（用户 curl 证实其账号可用 `agnes-video-v2.0`，且 **v2.0 与 2.5 是两套 API 格式**）：
  - `agnes-video-2.5*` → 2.5 格式（`mode:'ti2vid'`、`size:'720P'`、`seconds`、`aspect_ratio`；轮询带 `model_name`，取 `metadata.url`）
  - `agnes-video-v2.0` → **旧格式**：创建 `{model, prompt, width, height, num_frames: round(seconds×24)+1, frame_rate: 24}`（宽高按画幅映射，服务端自动校正预设）；轮询**不带 model_name**；完成地址在**顶层 `url`**（非 metadata）；`progress` 顶层真实百分比
- [x] **真实进度**：Agnes 两种代际轮询响应均含顶层 `progress`（0–100）→ reportProgress 显示真实百分比（SF 无此字段，显示状态+耗时）
- 测试：v2.0 创建 body 断言（width=1152/height=864/num_frames=121/frame_rate=24/无 mode）、顶层 url 提取、无 model_name 查询、agent 幻觉 model 被忽略断言

## 真机反馈修复 第三批（Agnes 轮询 GET）

- **只读诊断**：对照用户成功 curl 发现——Agnes 轮询端点 `/agnesapi` **仅接受 GET**，而工具用 `postJson`（POST）轮询 → 每次查询被服务端拒绝并被 `.catch(() => null)` 静默吞掉 → 状态永远无法更新（症状：卡"视频任务创建中…"+ 一直执行中）
- [x] `pollAgnesVideo` 改为 **GET 轮询**（fetch + Authorization 头，无 body）；网络失败仍 2s 重试
- [x] 轮询首次成功前先上报「排队中…」，消除创建后的显示空白
- [x] 测试断言：Agnes 轮询请求必须为 GET
