## 真机诊断（只读查询会话 DB）

用户真机场景（CS1.6 五杀集锦视频）失败链：
1. **Agnes mode 参数文档过时**：Flash 文档写 `text/keyframe/reference`，实际 API 报 `Input should be 'ti2vid', 'keyframes' or 'multi_reference'` → 我们发 `mode:"text"` 400
2. 模型自己试出正确值 `ti2vid`，但连续撞 **429 免费限流**（AgnesAI）
3. 复合工具 8 参数组合（mode/size/seconds/aspectRatio/媒体字段）导致模型反复试错

## 完成项（采纳用户提议：拆分为 4 个独立工具）

- [x] **`image-generate`（文生图，保留）**：删除 image 参数，纯文生图（Agnes/SF 双格式不变）
- [x] **`image-edit`（图生图，新增）**：`{prompt, image[](URL/本地→DataURI), size?, ratio?, model?}` → Agnes `extra_body.image` + `b64_json`；绑定非 Agnes 模型 → 明确报"仅支持 Agnes 图像模型"
- [x] **`video-generate`（文生视频，保留）**：删除 mode/媒体参数；Agnes **内部 `mode:'ti2vid'`（修正真实值）**；SF Wan2.2-T2V；无超时 + reportProgress 保留
- [x] **`video-from-frame`（图生视频，新增）**：`{prompt, firstFrame, lastFrame?, seconds?, aspectRatio?, model?}` → Agnes **内部 `mode:'keyframes'`**（first_frame/last_frame URL）；SF 用绑定模型 + `image` 参数（URL/DataURI）+ `image_size`（按画幅映射 1280x720 等）；**不做变体自动替换**（绑定模型原样使用，不支持图生视频的模型由 API 自然报错）；**本地路径素材报错**（Agnes 要求公开可访问 URL——文档约束）
- [x] TTS voice 描述强化："根据用户对音色性别/风格的要求从预置音色中选择"
- [x] 权限：新增 `{image-edit: allow}` / `{video-from-frame: allow}`（迁移自动补齐）
- [x] 429 友好化随错误透传（免费额度限流提示原样可见）
