# 024 · I13.1 — 工具矩阵（逐工具 加载×权限；取代能力组）

日期：2026-09-06
前置：I13（能力组方案）——用户试用后反馈"不是我要的"，改为**逐工具控制矩阵**。

## 用户需求（原文转述）

- Agent 设置：**列出所有工具**，每工具一个开关控制"是否加载（不加载则不进上下文）"，并可选择权限（可继承全局，也可选 allow/deny/ask）。
- 权限设置：**全局控制所列工具**，并新增每工具的开/关。

## 定稿决策（用户拍板）

1. 矩阵范围 = **仅内置功能工具**（MCP 保持服务器级三态、技能保持列表开关，均不入矩阵）。
2. 全局权限页 = **全量矩阵 + 只存偏离**；与默认一致即从存储删行（"恢复默认"=还原内置偏离为空，通配补充规则保留）。
3. Agent 每工具两列：**加载（跟随全局/开/关）＋ 权限（跟随全局/allow/deny/ask）**。
4. **移除能力组**概念与 UI（仅矩阵）。
5. plan/plan-exit 默认 enabled:false（仅 plan agent 强制开）；保留通配规则入口补充（mcp_* 等）；agent 起始默认跟随全局。

## 数据模型

- `provider.ts`：`PermissionRule` 增 `enabled?: boolean`（矩阵偏离）；`AgentDef` 去 `groups`，增 `toolOverrides?: Record<string,{load?:boolean;mode?:'allow'|'deny'|'ask'}>`；`tools`/`permission` 降级为**遗留字段**。
- `tools/policy.ts`（新，取代 groups.ts，后者删除）：`DEFAULT_TOOL_POLICY`（read/grep/glob/webfetch/websearch/skill/media 全部=开+allow；bash/write/edit/patch=开+ask；plan/plan-exit=关；未知新工具=开+ask 自动可用且保守）；`TOOL_INVENTORY`（展示分组 file/shell/web/media/skill/plan）；`globalToolPolicy`（规则偏离??默认）；`agentLoad`/`effectiveToolLoaded`（agent 覆盖 > 全局 enabled；遗留 tools 白名单）；`materializeAgentMatrix`（遗留 → toolOverrides 物化）。

## 生效规则（运行时）

```
全局 G(tool) = permissions.default 偏离 ?? DEFAULT_TOOL_POLICY
Agent A(tool): load = A.toolOverrides[tool].load ?? G.enabled
               mode = A.toolOverrides[tool].mode ?? (规则/默认判定)
注入 = registry 工具中 load==true（plan 靠默认关 + agent 开）
```

- `session-manager.ts`：runLoop / runSubAgent 暴露集改为逐工具 `effectiveToolLoaded` 过滤（取代 all-open/groups）；MCP `allowedMcpServers`（I13 服务器级）与技能过滤保留；`isAgentAllOpen` 改为"无 load 偏离=跟随全局"。
- `permission/index.ts`：`matchesRule` 去掉组展开（保留 `*`/尾缀 `*`/精确）；`checkPermission` 顺序 agent.toolOverrides.mode → 遗留 permission.* → 通配规则 → 默认策略 mode。
- `settings-defaults.ts`：`DEFAULT_PERMISSIONS.default = []`（默认策略集中到 policy）；DEFAULT_AGENTS（build/plan）保持 legacy 形状 → 由遗留解释保持语义（plan=白名单只读工具集）。

## UI（desktop）

- **AgentsTab**：移除能力组 → 工具矩阵两列下拉（跟随全局/开/关 ＋ 跟随全局/allow/deny/ask），按分组展示带中文名与 id；右上 ↺ 一键还原本 agent 为跟随全局；保留 MCP 三态区与技能开关；首次编辑自动 materialize（物化遗留白名单/权限数组）。
- **PermissionsTab**：内置工具全量矩阵（开关=加载、下拉=allow/deny/ask，偏离带"自定义"徽标，与默认一致自动删行即还原）；右上 ↺ 还原内置默认；保留"补充规则"列表（mcp_* 通配，可增删）；websearch 引擎区保留。
- i18n zh/en：`tools.labels.*`（20 工具中文名）、`tools.sections.*`、settings.agents.row/matrix*、settings.permissions.matrix*。
