# 025 · I13.2 — Agent 技能逐条（总闸+逐技能）+ i18n 修复

日期：2026-09-06
前置：I13.1（工具矩阵）。

## 反馈问题
1. Agent 设置页工具矩阵顶部显示 `settings.agents.loadCol / settings.agents.modeCol` 原始键名 → 引用了不存在的 i18n 键（只定义了 loadHeader/modeHeader）。
2. Agent 应能**列出技能**（frontend-design 等）并逐条 开启/关闭（进上下文）/继承全局。

## 决策（用户拍板）
- 技能控制 = **总闸 + 逐技能** 两层。
- Agent 级把某技能设"关" = **只摘出上下文清单**（不进 available_skills；skill 工具硬拦仍以全局 disabledSkills 为准）。

## 实现

### core
- `provider.ts`：`AgentDef` 增 `skillOverrides?: Record<string,'on'|'off'>`；`skillsEnabled` 注释明确为总闸。
- `skills/discovery.ts`：新增纯函数 `skillEnabled(name, agent, disabledSkills)`：
  `on→true；off→false；否则 跟随全局 = skillsEnabled!==false 且不在 disabledSkills`。
- `node/session-manager.ts`：runLoop 的 `<available_skills>` 过滤由"disabledSkills ∧ skillsEnabled"改为 `skillEnabled(s, agent, disabledSkills)`；`listSkills(cwd?)` 缺省 homedir、提供 cwd 含工作区层。
- 桌面 IPC：`ipc.ts`/`preload`/`main` 的 `skills:list` 加可选 `cwd`。

### desktop
- **AgentsTab**：
  - 修复 i18n：删除引用缺失键的副标题行，保留列头（`loadHeader/modeHeader`）。
  - 新增「技能」区（方框）：顶部总闸 Switch（skillsEnabled）；下方逐条行列出内置/全局/工作区技能（取活跃会话 cwd，`listSkills(cwd)`），每行 名+来源徽标 + **跟随全局/开/关** 下拉 → `skillOverrides`（写 'inherit' 即删键）。
- i18n zh/en：`agents.skillsLabel/skillsMaster/skillsHint/noSkills`。

### 测试（core 193）
- `skills.test.ts`（+3）：skillEnabled 跟随全局/总闸关+on 顶回/on 覆盖全局禁用/off 覆盖全局开。
- `session-matrix.test.ts`（+1）：两技能 alpha/beta；agent `alpha:off`、`beta:on`（全局禁用 beta）→ available_skills 含 beta 不含 alpha；`listSkills(dir)` 含工作区技能。
- 回归：I13.1 全部矩阵用例、mcp/skill/permission 通过。

## 真机反馈修复（I13.3）
- 用户要求 Agent 设置**去掉技能总闸**（彻底移除，非仅隐藏 UI；不加批量按钮）。
- 实现：`AgentDef.skillsEnabled` 字段删除；`skillEnabled()` 去掉总闸分支（`load(s) = skillOverrides on/off ?? 不在 disabledSkills`）；AgentsTab 删总闸 Switch 行、删 `skillsMaster` i18n、更新 `skillsHint`；skillEnabled/session 相关用例同步（移除总闸断言与 `skillsEnabled:false` 用例）。
- 迁移：已持久化 agent 若曾设 `skillsEnabled:false` 将被忽略，按"跟随全局"处理。
- 验证：typecheck ✅ · 测试 ✅（core 192 + desktop 11 = 203）· build ✅ · Electron 冒烟 ✅。
