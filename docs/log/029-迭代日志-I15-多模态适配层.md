## 架构

`multimodal.ts`（原 614 行、8 工具内联 `isAgnes` 分支）→ 拆为：

```
core/src/adapters/
  types.ts    MMAdapter 统一接口（8 特性键=工具 id）+ MMBinding/MMCtx/GenImage/RerankHit/Video*Req
  shared.ts   postJson/downloadAsDataUrl/toDataUrl/extractImageOutputs/readProgress/statusStarted + 超时常量（平移，逐字节不变）
  openai.ts   通用（SiliconFlow 格式）：embed/rerank/图(image_size 精确+batch)/视频(submit+Succeed 轮询)/图生视频(image+尺寸映射)/tts(<model>:voice 前缀)/asr(multipart)；supports: image-edit=false
  agnes.ts    图(档位 size+ratio+return_base64)/图生图(extra_body.image+b64)/视频(v2.5 ti2vid·keyframes+v2.0 旧格式 width/height/num_frames；GET /agnesapi 轮询+metadata.url)/首尾帧素材 URL 规则；supports: 仅图像/视频四项
  index.ts    pickAdapter(apiStyle 优先 → providerId==='agnes'||/^agnes-/ 隐式) + ensureSupport(未适配→中文清晰报错，不发未知请求)
```

工具层（multimodal.ts，现 ~300 行薄壳）只保留：resolveBinding(+providerId/apiStyle)、参数校验、ticker 计时进度、saveTemp、richOutput、下载视频、工具定义（描述/schema 不变）。

## 变更

- `provider.ts`：`ProviderConfig` 增 `apiStyle?: 'openai'|'agnes'`（type-only import，浏览器入口无 node 依赖）
- `tools/multimodal.ts`：8 个 doX 分支全部下沉；image-edit 对非 Agnes 保留原换绑文案；embed/rerank/tts/asr 绑定到 Agnes 模型时经 `ensureSupport` 明确报「X当前不支持该模型所属接口…请到设置→模型换绑」，**不再向未知端点发请求**
- `ModelsTab`：Provider 编辑器加「接口风格」下拉（自动/OpenAI 兼容/Agnes）+ hint；i18n zh/en

## 测试（core 207，新增 adapters.test 6）
