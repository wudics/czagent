# 031 · I14.1 — 脚本子进程化（删除 vm/粘贴模式，唯一入口路径 + 启动回收）

日期：2026-09-06
前置：I14（目录入口 + 粘贴双模式，vm 沙箱）。用户反馈演进：入口模式不需要输入框 → 粘贴模式与 vm 沙箱整体删除 → 唯一路径 = 工作目录入口 + node 子进程（fs 不限制、信任工作区代码）→ 脚本超时默认不限、可设上限。

## 决策（用户拍板）
- 入口模式**隐藏输入框**→ 进一步**删除粘贴代码模式与 📎 附件**（脚本会话唯一交互 = ▶ 运行入口）。
- 执行结构 = **B-统一**（无分层）：vm 沙箱与 `script/runner.ts` 删除。
- **fs 不限制**：子进程完整权限，信任模型 = `npm run`（fs 硬边界决策随 vm 移除而消解；工具操作照常走权限卡）。
- 超时：**默认 0=不限**，`general.scriptTimeoutMinutes` 可设上限（>0 到期 abort→5s→kill）。
- 补强（"默认不限"的必要条件）：**启动状态回收** —— SessionManager 构造时把 running/queued 复位 idle（否则关应用时子进程死亡但 DB 卡"运行中"，重启后永久拒收消息）。

## 实现

### core
- 新 `script/child.ts`：`runEntryChild()`——esbuild **bundle**（platform=node、CJS、target node22、inline sourcemap、absWorkingDir=cwd → **node_modules 与 ESM-only 包打进产物**）→ 临时 `.cjs` = PRELUDE(ctx 桥+console 接管+abort 帧处理) + bundle + GLUE(default(ctx)→result/fail 帧) → `spawn(process.execPath, ['--enable-source-maps', file], {ELECTRON_RUN_AS_NODE:'1'})`（纯 node/测试环境自动退化；flag 异常时 stderr 透出）。
- stdio **JSON-RPC 桥**（换行分帧，非 JSON 行降级为日志）：子→主 `tool/agent/ask/log/result/fail`；主→子 响应帧 + `abort`。tool/agent 回调接回既有 `runScriptTool`（权限管线+工具卡片进会话消息流）与 `runSubAgent`（`[agent]` 实时流）；`question/task` 在桥侧明确拒绝（与主会话专用一致）。
- 超时：`timeoutMs>0` 时到期 abort+立即 reject"脚本执行超时（Xs）"+5s kill；外部 stop 同路径（"未响应停止→强制结束"）。
- `script/types.ts`：`ScriptContext/ScriptRunOptions`（vm 契约）删除；保留 `ScriptAgentRunOptions`；新增 `ChildRunHandlers/ChildRunOptions`。`script/runner.ts` 删除。
- `session-manager.ts`：sendMessage 对 script 会话**恒**探测入口（无入口抛错，无副作用）+ 消息标记 `▶ 运行入口：<file>` + `startScriptFileLoop`（不再读源码，直接子进程）；pumpQueue 补位对 script 会话重探入口（原实现只起 chat 循环的缺陷一并修复）；构造函数启动回收。
- `provider.ts`：`GeneralSettings.scriptTimeoutMinutes?: number`；`SendMessageInput.runEntry` 移除；`settings-defaults` 默认 0。

### 桌面
- `InputBar`：script 会话改为**单行操作条**——提示「将运行入口 czagent.ts」或「未找到入口脚本：候选…」+ ▶（无入口禁用）/■；textarea、📎、附件 chips、入口/粘贴切换全部移除；`chat.scriptPlaceholder/entryPlaceholder/entryRun/pasteCode` → `chat.scriptRunHint/noEntryFile`。
- `chat` store：`send(text, ids, {allowEmpty})`（脚本会话空文本放行）。
- `GeneralTab`：「脚本超时（分钟）」+ hint（0=不限）。

### 文档
