# 038 · 添加模型仅保存 + 新增 bigmodel/qwen/openrouter 对话引擎

日期：2026-09-09
前置：I 迭代 037 重构后的两项跟进——①用户反馈：添加对话模型时不应自动抢设默认绑定（"保存并设为默认"按钮越权），保存后应由用户在能力绑定区手动设置默认；②用户要求参考官方文档（bigmodel 智谱 / qwen 阿里云百炼 / openrouter）各增加独立对话引擎，遵循 037 的"每家独立引擎"recipe。

## 现状结论（调研）

- **保存行为**：`ChatModelDialog.save()` 新增分支在 `addChatModel` 后紧跟 `updateBinding('chat', saved.id)`，无条件把新模型设为默认对话模型；按钮文案 `saveAndDefault` 与行为一致但不符合用户预期。
- **三家协议差异**（对照官方文档）：
  - bigmodel（`https://open.bigmodel.cn/api/paas/v4`）：标准 OpenAI 兼容 SSE；思考用 `thinking:{type:enabled/disabled}` + `reasoning_effort`（默认 max）；思维链 `reasoning_content`；默认 `clear_thinking` 清历史思考，无需回传。
  - qwen（`https://dashscope.aliyuncs.com/compatible-mode/v1`，DashScope OpenAI 兼容模式）：思考用 `enable_thinking` + `reasoning_effort`（3.8 系 low/medium/xhigh）；思维链 `reasoning_content`；qwen3.8-max `preserve_thinking` 默认 true，**必须完整回传历史 reasoning_content**。
  - openrouter（`https://openrouter.ai/api/v1`）：标准 OpenAI 兼容；思考用统一 `reasoning:{effort}`（none/minimal/low/medium/high/xhigh/max，另支持旧写法 `reasoning_effort`）；思维链 delta 字段为统一格式 **`reasoning`**（非 reasoning_content）。

## 决策（用户拍板）

- 添加模型"只需保存"，不自动设默认；按钮文案统一为"保存"。
- 三家各建独立引擎文件（`llm/engines/chat/`），差异写死在实现内；`openai-compatible` 保持兜底居末。

## 变更

- **保存行为**（`desktop/renderer/components/settings/ModelsTab.tsx`）：`save()` 删除 `updateBinding('chat', saved.id)`，新增仅落 `addChatModel`；按钮去掉 `isNew` 分支统一 `settings.models.save`；locales（zh-CN/en-US）删除死键 `saveAndDefault`。
- **新引擎**（`core/src/llm/engines/chat/`）：
  - `bigmodel.ts`：off → `{thinking:{type:'disabled'}}`；on → `{thinking:{type:'enabled'}}`；deep → `+reasoning_effort:'max'`；不回传历史 reasoning（对齐其默认 clear_thinking）。
  - `qwen.ts`：off → `{enable_thinking:false}`；on → `{enable_thinking:true}`；deep → `+reasoning_effort:'xhigh'`；`reasoningPassthrough: true`（qwen3.8 preserve_thinking 要求）。
  - `openrouter.ts`：`reasoningField:'reasoning'`（统一思维链字段）；off → `{reasoning:{effort:'none'}}`；on → 不发参数（平台默认）；deep → `{reasoning:{effort:'max'}}`。
- **注册**（四步 recipe）：`provider.ts` `ChatImplId` 加 `'bigmodel'|'qwen'|'openrouter'`；`engines/index.ts` CHAT_ENGINES 注册三条；`engines/catalog.ts` CHAT_IMPL_META 插入三条（openai-compatible 保持兜底居末）：`BigModel（智谱 GLM）` 默认 `https://open.bigmodel.cn/api/paas/v4`、`Qwen（阿里云百炼）` 默认 `https://dashscope.aliyuncs.com/compatible-mode/v1`、`OpenRouter` 默认 `https://openrouter.ai/api/v1`。
- **测试**（`core/test/adapters.test.ts`）：`chat 引擎差异` cases 加三行（on/deep/off 请求体断言）；新增"openrouter 统一 reasoning delta → reasoning-delta"用例。核心 39 → 43 项。
- **文档**：`docs/dev/llm-engine.md` 重写为新架构（§4.1 七家引擎差异表、模型目录改为用户自建）；`docs/dev/architecture.md` 目录树与决策描述对齐；`docs/dev/ui-design.md` 模型管理段更新为三区结构；`docs/dev/data-model.md` §2.4 implId 列表补充。
