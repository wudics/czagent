从本地文件系统读取文件或目录。如果路径不存在，将返回错误。

用法：
- filePath 参数应为绝对路径。
- 默认情况下，此工具从文件开头最多返回 2000 行。
- offset 参数是从 1 开始的行号。
- 要读取后面的章节，请再次调用此工具并指定更大的 offset。
- 使用 grep 工具在大型文件或长行文件中查找特定内容。
- 如果你不确定正确的文件路径，使用 glob 工具按 glob 模式查找文件名。
- 返回的内容每行都以 `<line>: <content>` 的行号作为前缀。例如，如果文件内容是 "foo\n"，你将收到 "1: foo\n"。对于目录，条目每行一个（不带行号），子目录后跟 `/`。
- 任何超过 2000 个字符的行都会被截断。
- 当你知道有多个文件要读时，并行调用此工具。
- 避免微小的重复切片（30 行块）。如果你需要更多上下文，请读取更大的窗口。
- 此工具可以读取图像文件和 PDF，并将它们作为文件附件返回。
