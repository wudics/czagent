- 从指定 URL 抓取内容
- 输入为 URL 和可选的 format
- 抓取 URL 内容，转换为请求的格式（默认 markdown）
- 返回指定格式的内容
- 当你需要检索和分析 web 内容时使用此工具

用法说明：
  - 重要提示：如果存在其他提供更好 web 抓取能力、更针对任务或有更少限制的工具，优先使用那个工具而不是这个。
  - URL 必须是完整有效的 URL
  - HTTP URL 会自动升级为 HTTPS
  - 格式选项："markdown"（默认）、"text" 或 "html"
  - 此工具是只读的，不修改任何文件
  - 如果内容非常大，结果可能会被总结
