0036 - 使用 diff 识别哪些文件发生了变化
0037 - 使用 `git status --short` 识别未跟踪的文件，然后读取它们的完整内容
0038 - 读取完整文件以理解现有模式、控制流和错误处理
0039 - 检查现有的风格指南或约定文件（CONVENTIONS.md、AGENTS.md、.editorconfig 等）

0044

0008 # 定制 opencode
0009 
0010 opencode 严格验证自己的配置，当字段出错时拒绝启动。下面的结构覆盖了常见的表面区域，但它们是**总结，而不是权威来源**。
0011 
0012 ## 完整 schema 参考
0013 
0014 每个配置选项的权威列表——包含字段类型、枚举、默认值和描述——位于已发布的 JSON Schema 中：
0015 
0016 **<https://opencode.ai/config.json>**
0017 
0018 如果某个字段没有在此技能中记录，或者你需要确认一个确切的结构后再写配置，**直接抓取该 URL 并阅读 schema**，而不是猜测。opencode 对无效配置会硬失败，所以错误结构的代价是启动失败。
0019 
0020 此外，每个 `opencode.json` 都应该声明 `"$schema": "https://opencode.ai/config.json"`，这样用户的编辑器就能在输入时捕获错误。
0021 
0022 ## 应用改动
0023 
0024 配置在 opencode 启动时加载一次，不会热重载。保存对 `opencode.json`、agent 文件、技能、插件或任何其他配置期文件的改动后，**告诉用户退出并重启 opencode** 以让改动生效。在此之前，正在运行的会话会继续使用已加载的配置。

0028 | 作用域 | 路径 |
0029 | ----------------------------- | ------------------------------------------------------------------------------------------------------------------------- |
0030 | 项目配置 | `./opencode.json`、`./opencode.jsonc` 或 `.opencode/opencode.json`（opencode 从 cwd 向上走到 worktree 根目录） |
0031 | 全局配置 | `~/.config/opencode/opencode.json`（不是 `~/.opencode/`） |
0032 | 项目 agents | `.opencode/agent/<name>.md` 或 `.opencode/agents/<name>.md` |
0033 | 全局 agents | `~/.config/opencode/agent(s)/<name>.md` |
0034 | 项目技能 | `.opencode/skill(s)/<name>/SKILL.md` |
0035 | 全局技能 | `~/.config/opencode/skill(s)/<name>/SKILL.md` |
0036 | 外部技能（自动加载） | `~/.claude/skills/<name>/SKILL.md`、`~/.agents/skills/<name>/SKILL.md` |

0284 ## 权限
0285 
0286 ```json
0287 "permission": {
0288   "edit": "deny",
0289   "bash": { "git *": "allow", "rm *": "deny", "*": "ask" },
0290   "external_directory": { "~/secrets/**": "deny", "*": "allow" }
0291 }
0292 ```
0293 
0294 动作：`"allow"`、`"ask"`、`"deny"`。
0295 
0296 每个工具的值的形态：`"allow"` 简写（视为 `{"*": "allow"}`），或 `{ pattern: action }` 对象。在对象内，**插入顺序很重要**。opencode 评估**最后一个**匹配规则，所以把宽泛规则放在前面，窄规则放在最后。
0297 
0298 `permission: "allow"`（顶层的字符串）是 "允许一切" 的简写，通常不是用户想要的。
0299 
0300 已知的 permission 键：`read, edit, glob, grep, list, bash, task, external_directory, todowrite, question, webfetch, websearch, lsp, doom_loop, skill`。其中一些（`todowrite, question, webfetch, websearch, doom_loop`）只接受扁平动作，不接受按模式的对象。
0301 
0302 `external_directory` 模式是文件系统路径（使用 `~/`、绝对路径或如 `~/projects/**` 的 glob）。
0303 
0304 按 agent 的 `permission:` 覆盖顶层 `permission:`。Plan Mode 位于 `plan` agent 的 permission 规则集上（`edit: deny *`）。
