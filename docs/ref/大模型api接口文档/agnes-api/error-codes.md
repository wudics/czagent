# 通用错误码与解决方案

> 文档来源：https://wiki.agnes-ai.com/en/docs/code.md

## 错误码总表

| 状态码 | 含义 | 常见原因 | 解决方案 |
|--------|------|----------|----------|
| 400 | 请求参数无效 | 请求体格式错误、缺少必填参数、参数类型错误、上下文超限 | 检查必填参数、验证 JSON 格式、压缩提示词和对话历史 |
| 401 | 认证失败 | API Key 错误、过期、配置不正确、缺少 Authorization 头 | 检查/重新生成 API Key，确认 Header 配置 |
| 402 | 余额不足 | 账户余额或 Token Plan 配额不足、订阅状态异常 | 检查余额、充值或升级套餐 |
| 403 | 无权限 | API Key 无权访问请求的模型、IP/区域受限 | 确认模型访问权限、检查订阅/企业验证状态 |
| 404 | 资源不存在 | API 地址错误、Base URL 配置错误、路径错误、模型名错误 | 检查 Base URL（注意 `/v1` 重复问题）、模型名、路径 |
| 405 | 方法不允许 | HTTP 方法错误（该用 GET 用了 POST 等） | 按文档使用正确方法 |
| 408 | 请求超时 | 网络不稳定、内容过大、长任务处理时间过长 | 重试、缩短输入、增大客户端超时、增加重试逻辑 |
| 409 | 资源冲突 | 重复提交任务、资源状态不允许操作 | 避免短时间重复提交、检查任务状态、客户端加防重保护 |
| 413 | 请求体过大 | 上下文过长、base64 图片过大、上传文件超限 | 压缩内容、分批提交、图片用公开 URL 代替 base64 |
| 415 | 媒体类型不支持 | 文件格式不支持、Content-Type 错误 | 检查文件格式（图片用 PNG/JPG/JPEG/WEBP）、修正 Content-Type |
| 422 | 参数值无效 | 参数超出范围、图片 URL 无法访问、base64 无效 | 按错误提示修改参数、确认图片 URL 公开可访问 |
| 429 | 请求频率超限 | 超过 RPM 限制（免费用户 RPM 20）、并发过高 | 等待 1 分钟重试、降低频率、控制并发、升级 Token Plan |
| 431 | 请求头过大 | Header 内容过多、Authorization 异常 | 减小 Header、移除多余 Cookie/自定义 Header |
| 499 | 客户端关闭请求 | 客户端超时断开、浏览器/工具中断、网络切换 | 重新发送、增大超时、避免中断、长任务用异步轮询 |
| 500 | 服务器内部错误 | 参数异常触发服务异常、图片尺寸非 16 倍数、视频尺寸非 64 倍数 | 检查参数（图片尺寸需为 16 的倍数、视频为 64 的倍数）、修改参数重试 |
| 502 | 网关错误 | 网络问题、DNS/代理配置、上游服务波动 | 检查网络、更换网络/DNS、检查代理、稍后重试 |
| 503 | 服务不可用 | 模型名错误、模型列表获取失败、未选回退模型、服务临时不可用 | 检查模型名、重新获取模型列表、选择回退模型、启用路由 |
| 504 | 网关超时 | 上游响应超时、图像/视频/长上下文任务过慢、高峰期负载高 | 稍后重试、缩短输入、降低生成规格、减少并发、增大超时 |
| 520 | 未知错误 | 网络连接、网关行为、上游临时波动、代理/DNS 配置 | 重试、检查网络/代理/DNS、持续则提交完整错误信息 |
| 522 | 连接超时 | 网关连接上游超时、网络/代理/DNS 问题 | 重试、检查网络、更换 DNS、更换网络环境 |
| 524 | 超时发生 | 连接建立但上游处理过慢、长任务、高负载 | 稍后重试、降低复杂度、缩短上下文、用异步任务轮询 |

## 高频错误码详解

### 400 Bad Request

**含义**：请求参数无效，服务器无法处理请求。

**常见原因**：
- 请求体格式错误
- 缺少必填参数
- 参数类型错误
- 上下文长度超过模型限制
- 第三方工具参数格式不兼容
- 视频生成参数错误
- 与 Codex 等工具的请求格式不兼容

**解决方案**：
- 检查是否包含所有必填参数
- 验证 JSON 格式有效
- 压缩提示词和对话历史
- 新开对话重试
- 检查视频生成参数（FPS、时长、分辨率、宽高比）
- 使用 Codex 等第三方工具时检查并调整请求格式

### 401 Unauthorized

**含义**：认证失败，请求未通过身份验证。

**常见原因**：API Key 错误、过期、配置不正确、缺少 Authorization 字段、API Key 属于其他账号。

**解决方案**：检查 API Key 是否完整复制、确认有效性、重新生成、检查 Header 配置、确认账号归属。

### 402 Payment Required

**含义**：账户余额或可用配额不足。

**常见原因**：余额不足、Token Plan 配额不足、订阅状态异常、充值未生效。

**解决方案**：检查余额、检查 Token Plan 状态、充值或升级、降低单次请求成本、充值生效后重试。

### 429 Too Many Requests

**含义**：请求频率过高，超过当前账户的 RPM 限制。

**常见原因**：RPM 超限（免费用户限制 RPM 20）、并发请求过多、短时间重复请求、自动重试频率过高。

**解决方案**：等待 1 分钟重试、降低请求频率、控制并发数、添加合理重试机制、请求量大时升级 Token Plan。

### 500 Internal Server Error

**含义**：服务器内部错误，或请求参数触发了服务异常。

**注意**：图像生成尺寸必须是 **16 的倍数**；视频生成尺寸必须是 **64 的倍数**。

**解决方案**：检查请求参数、修改尺寸后重试、持续则提交错误详情给技术支持。

### 503 Service Unavailable

**含义**：服务临时不可用，或第三方工具配置问题导致请求失败。

**常见原因**：模型名错误、模型列表获取失败、未选择回退模型、路由未启用、工具实际发送到错误模型。

**解决方案**：检查模型名、重新获取模型列表、选择回退模型、启用路由、检查工具的测试模型和备用模型配置。
