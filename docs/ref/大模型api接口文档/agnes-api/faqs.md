# 常见问题（FAQ）

> 文档来源：https://wiki.agnes-ai.com/en/docs/faqs.md

## 1. 这个平台是什么？

本平台为开发者提供免费 AI API 服务，可将文本、图像、视频和多模态 AI 能力集成到应用程序中。

## 2. API 是免费的吗？

是的。核心 AI 模型可无限期免费使用，可无时间限制地持续使用免费模型。

## 3. 免费用户的限制是什么？

免费用户受 RPM 限制（每分钟请求数可能受限）。达到限制后，请等待片刻再发起请求。

## 4. 多模态模型免费吗？

是的。完整的多模态模型均可免费使用，包括文本、图像、视频和多模态能力。

## 5. 如何开始使用？

注册后，在仪表盘中生成 API Key，即可使用文档中的示例开始发起请求。

## 6. 如何查看使用量？

可在仪表盘的 "Usage" 或 "Billing" 下查看请求用量、限制及相关详情。

## 7. 为什么 API 响应慢？

可能原因：服务器负载高、提示词过大、网络延迟或 RPM 限制。可稍后重试、减小请求体或切换到其他可用模型。

## 8. API Key 丢失怎么办？

可在仪表盘中重新生成新 API Key。出于安全考虑，应立即删除旧 Key。

## 9. 在哪里查看文档？

可在文档站查看集成指南和 API 示例，包含创建 API Key 和调用模型的分步说明。

## 10. 如何获取支持？

一般问题、文本类咨询或集成支持，可通过邮件或社区联系：

**邮箱**：support@agnes-ai.com

## 图像模型 FAQ（Image 2.0 Flash）

### 支持文生图吗？
支持。文生图请求仅需 `model`、`prompt`、`size`，无需 `image` 参数。

### 支持图生图吗？
支持。图生图请求需在 `extra_body.image` 中传入输入图片。

### 图生图需要 tags 吗？
不需要。不要传 `tags: ["img2img"]`，使用 `model`、`prompt`、`size` 和 `extra_body.image` 即可。

### 为什么顶层 response_format 会报错？
在此 API 结构中，`response_format` 应放在 `extra_body` 内。放在顶层可能导致 400 错误。

### 输入图片 URL 无法访问怎么办？
使用可公开访问的 HTTPS 图片 URL。如果图片无法公开，请使用 Data URI Base64 输入。

### 客户端超时如何配置？
图像生成可能耗时数秒到数十秒，建议客户端超时设置为 `60s - 360s`。
